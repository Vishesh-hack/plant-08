# Notes and Suggestions

- Create a small admin page to view plant data directly in the browser.
- Install and use MongoDB Compass for GUI access to the database.
- Use MongoDB Atlas UI (Browse Collections) to inspect plant documents.
- Use API calls like /api/plants/all to spot-check data output.

## Future Feature Ideas

- Admin dashboard to view, filter, and edit plant data (protected route).
- Plant comparison view (side-by-side stats and care needs).
- Advanced filters (soil type, sunlight hours, water frequency, climate zone).
- Search history and saved searches.
- Favorite plants collection with tags.
- Plant calendar with sowing and harvest reminders.
- Seasonal alerts and care notifications.
- Growth tracker with photos and notes per plant.
- Disease and pest lookup with prevention tips.
- Yield estimator based on spacing and plot size.
- Interactive map of India growing regions per plant.
- Watering schedule generator and export to calendar.
- Offline mode cache for key plant pages.
- Image gallery per plant (user-uploaded or curated).
- Accessibility pass (keyboard-first, contrast checker, font scale controls).
